Release candidate for 0.5.0, covering everything merged to `main` since 0.4.0.

## Cash Hub (#90)
- Bearer (identity-less) multi-recipient cash tokens, paired with a bech32 `lokicash1...` token
- `cash_transfer` for splitting a slice off a cash wallet, `cash_consolidate` for combining several slices this node custodies into one new token, `list_recipients` for enumerating a wallet's slices
- Per-slice redeem fees (`redeem_fee_ppm`) and a configurable expiry ceiling, including no-expiry (`MaxExpSecs == 0`)
- Optional mint provenance: a recoverable-ECDSA node signature attesting a token's minter and amount, across `mint_cash`, `cash_transfer`, `cash_consolidate`, and the admin HTTP mint path
- `cash_transfer`'s partial split now mints two fresh wallets (carved + remainder) instead of shrinking the source in place — a wallet's committed amount is immutable everywhere
- NIP-CASH's and NIP-CW's per-call proofs moved off the shared, colliding kind 35521 onto their own kinds (23198 / 23199)
- New integration suite driving Cash Hub / Circle Hub through the real `nmilat` client SDK, proving wire-compatibility with the published caller-side library
- 2026-08-31 security/financial/UX audit round (5 independent reviewers): fixed a High-severity Circle Wallet spend-cap bypass (a member could silently disable their own cap via a sub-loki `max_amount`) plus 7 additional findings — fee-skim visibility, cash-specific expiry messaging, a silently-skipped rate-limit test, `cash_consolidate` dedup-guard granularity, 128-bit-safe fee-skim overflow handling, and more
- `grpc`/`flnd` dependency bumps resolving GO-2026-6061, 5668, 4887, 4883

## Fixes
- Swap claim/refund transactions now broadcast through the node's own FLND connection instead of a third-party `lightz` API, and compute the txid locally from the signed transaction rather than trusting the broadcaster's response (#93)

## CI / Release process
- `release.yaml` no longer picks up stale build artifacts left over from earlier ad-hoc `workflow_dispatch` runs — it now pulls all platform artifacts from the single aggregated `build-all.yaml` run (#82)
- Fixed a duplicate Linux server tarball filename collision across the legacy/modern build matrix legs that broke asset upload (#84)
- Hyphenated `VERSION` values (`-rc`, `-alpha`, `-beta`, ...) — including this release candidate — now publish as GitHub prereleases instead of stable releases
