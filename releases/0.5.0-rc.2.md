Release candidate for 0.5.0, covering everything merged to `main` since 0.5.0-rc.1.

## Security
- Closed a real, currently-exploitable order-forgery gap in the LSPS5 Nostr notification path: any trusted LSP's signed Nostr event could change the state of *any* order, not just ones it created. The ownership check that already existed on the HTTP webhook path now lives inside the shared function both transports call.

## Cash Hub
- `cash_consolidate` now accepts `pubkey`, `connection_key`, or `bearer` targets, and `pubkey` or `connection_key` sources (each independently proven; connection_key sources require a live-trusted attestation, checked once per call to close a TOCTOU window across a multi-source batch). Bearer sources remain deferred.
- `mint_cash` wallet creation is now atomic — app creation, pubkey registration, and claim-row insertion happen in one DB transaction, closing a gap where a mid-creation failure could strand a partial, unfunded wallet row.
- Recipients can now be addressed by `nconnection1...`, `npub`, or NIP-05 in the Cash UI, not just raw hex pubkeys.
- A bearer note's token and secret are now merged into a single gift string instead of two separate values to copy/track.
- Saved Identity Authorities now show their npub, profile picture, display name, and NIP-05 instead of a raw hex pubkey.
- Assorted UX fixes: a new recipient row defaults to Bearer and leads with the Bearer tab; a bearer secret's one-time reveal can no longer be dismissed by accident, nor become uncopyable if token encoding degrades; a missing `cash_consolidate` permission scope entry (was breaking app detail pages) is added; LokiCash tokens no longer show NWC connection-status UI; a user's own Cash/Circle Hub or Wallet is no longer called "an app" in its own UI.
- Migrated onto `nmilat`'s own published `nipcash`/`nipcw` request/response types and method-name constants instead of maintaining parallel copies, and bumped to the newly published `github.com/ohstr/nmilat v0.3.0`, dropping the temporary local `replace` directive used while the connection_key-sources wire change was still unpublished. Full unit + integration suites (including the integration suite's real `nmilat` client SDK path) verified green against v0.3.0.

## Docs
- Several rounds of NIP-CASH/NIP-CW proofreading against the reference NIPs: cut duplicated rationale and cross-reference drift, fixed stale/self-referential references, added missing sequence-diagram steps, and closed one real spec gap.
