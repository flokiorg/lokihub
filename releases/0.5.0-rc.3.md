Release candidate for 0.5.0, covering everything merged to `main` since 0.5.0-rc.2.

## Desktop App
- Windows: the desktop app now runs frameless, with its own minimal minimize/maximize/close bar instead of the native title bar.
- macOS: the native title bar is hidden and content extends full-size, keeping only the traffic-light buttons (close/miniaturize/zoom) - the same look used by apps like VS Code and Slack.
- Linux is unchanged - window manager chrome varies too much across distros to give a frameless window a reliably "modern" look there.
- Fixed the sidebar's logo/header rendering underneath the window controls (native traffic lights on macOS, the custom bar on Windows) instead of below them.
- macOS: fixed the native window's own corner background (behind the inset traffic lights) showing a mismatched default color instead of the app's actual theme - it now matches on launch and follows every theme switch and light/dark toggle live.
- Removed a dead, always-overridden background class on the onboarding/setup screen's hero panel (no visual change).
- macOS: the title bar no longer reserves layout space above the traffic lights - it now overlays a transparent drag region on top of the full-size WebView, so page backgrounds extend all the way behind the buttons instead of stopping short with a gap.

## Security
- Bumped `google.golang.org/grpc` to v1.83.2, fixing GO-2026-6348 (heap exhaustion via HTTP/2 DATA frame fragmentation), reachable through flnd's LND client (channel close, custom message subscriptions) and the HTTP service's shutdown path.

## Dependencies
- Bumped to the newly published `github.com/ohstr/nmilat v0.3.0`, dropping the temporary local `replace` directive used while the `cash_consolidate` connection_key-sources wire change was still unpublished.
